四城 Sentinel-2 特征构建（游戏本便携版）
==========================================

用途
----
这个文件夹会为 Los Angeles、Phoenix、Houston、Chicago 构建滞后 Sentinel-2
地表光学特征。它只读取公开的非热红外卫星数据，不需要 Earthdata token，也不会训练模型。

如何开始
--------
1. 把整个 GAMING_LAPTOP_SENTINEL 文件夹复制到游戏本的本地 NVMe 硬盘。
2. 保证网络稳定，并预留至少 150 GB 可用空间；实际网络读取量可能很大。
3. 双击 START_HERE.cmd。
4. 第一次启动会离线创建 Python 环境，通常需要几分钟。
5. 浏览器会打开 http://127.0.0.1:8769/。
6. 下载线程选 6（推荐）或 8；同时处理 acquisition 保持 1 最稳，32 GB 内存可尝试 2。
7. 点击“开始 / 继续”。

暂停与恢复
----------
- 在网页点击“安全暂停”，等“运行”变成 0 后即可关机或复制文件夹。
- 下次仍双击 START_HERE.cmd，再点击“开始 / 继续”；已经完成的 acquisition 不会重算。
- 单个任务失败会自动重试；进程意外退出时，控制页会自动重启它。
- 不要手动删除 data\interim 下的缓存或 status.json。

完成后带回结果
--------------
1. 等网页显示 complete（或先安全暂停并等运行数为 0）。
2. 关闭进度页窗口。
3. 双击 PACKAGE_RESULTS.cmd。
4. 程序会在本文件夹的上一级生成：
   - GAMING_LAPTOP_SENTINEL_RESULTS_时间.zip
   - 同名 .zip.sha256 校验文件
5. 把这两个文件复制回原电脑。不要只复制某一个 parquet。

性能说明
--------
- 这一步主要消耗网络、CPU、内存和 SSD；RTX 4060 基本不会参与。
- 6/8 表示并行网络读取线程，不表示同时把 6/8 个完整 acquisition 放进内存。
- 若内存接近满载，把 acquisition 并发改回 1。

常见情况
--------
- 页面打不开：确认命令窗口仍开着；重新双击 START_HERE.cmd。
- 8769 端口被占用：关闭旧的进度程序后重试。
- 网络中断：程序会重试。长时间无进展时先安全暂停，恢复网络后继续。
- Windows Defender 首次扫描大量 wheel 或缓存文件时，启动可能暂时变慢。

安全提示
--------
此任务不要求任何账号 token。不要把密码、token 或浏览器 cookie 放进本文件夹。
