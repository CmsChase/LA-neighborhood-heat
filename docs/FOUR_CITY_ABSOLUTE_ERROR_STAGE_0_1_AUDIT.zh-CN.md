# 后四城绝对温度误差研究：阶段 0–1 合同与既有产物审计

状态：**完成；停在阶段 0–1，未进入候选训练或评分。**
日期：2026-09-16

## 1. 本轮范围

本轮只固定 C1/C2/C3 开发合同并审计既有产物。研究目标是优先降低 Denver、Atlanta 的绝对温度高估，同时保护 Seattle 的既有精度；原 M3 社区相对温差分支保持不变。本轮没有重新优化 LA、没有启动成都迁移、没有访问 LA 2025、没有下载或构建预测变量，也没有生成、训练或评分 C1/C2/C3。

固定合同位于 `experiments/four_city_absolute_error/fixed_contract.toml`。后四城已经揭盲，因此只作为历史压力测试，不能改变源城市选出的候选，也不改变原盲测结论。

## 2. 固定实验合同

三个候选共享：

`absolute_prediction = candidate_level + frozen_original_m3_anomaly`

其中 anomaly 是原完整 M3 保存模型中的 23 特征 anomaly 分支，并在每个城市—日期的**完整固定预测集合**上取中位数为零；不得在评分子集上重新中心化后冒充正式绝对预测。

| 候选 | 固定定义 | 禁止的事后改动 |
| --- | --- | --- |
| C1 | 完整预测集合上 B1 tract 预测的城市—日期中位数 + 原 anomaly | 不加城市特例，不换天气窗口 |
| C2 | 测试城市完整集合的城市中位海拔落在训练折源城市范围内时使用原 M3 level，否则回退 C1；边界包含在范围内 | 不加 Denver 分支、缓冲、软门控或外城选阈值 |
| C3 | 完整集合 d−1 Tmax 中位数作锚点，加固定 `DecisionTreeRegressor(criterion="absolute_error", max_depth=2, min_samples_leaf=10, random_state=20260916)` 修正 | 不搜索窗口、树深、叶大小、交互或附加候选；不输入海拔、经纬度、城市/tract ID |

### 源城市选择

- 四源城市：Los Angeles、Phoenix、Houston、Chicago；QA 固定为 QA4K。
- 整城 nested LOSO；每个外层折的选择只能使用其余源城市的整城内层留出结果。
- 合格条件：总体等城市/等日期绝对 MAE 不差于 B1，且最差源城市 MAE 不差于 B1 的最差城市。
- 合格候选先按最差城市 MAE 排序；相差不超过 0.01°C 时按总体 MAE，再按 C1、C2、C3 的简单度顺序。
- 没有合格候选则保留 B1。外层分数只评估选择程序，不能直接选最终方案；最终方案用全部四源城市执行相同的固定源城市规则。后四城结果不得换赢家。

### 已揭盲四城压力门槛

源城市唯一选出的方案一次性用于四城固定批次：Denver ≤ 3.8993°C，Atlanta ≤ 4.3150°C，Seattle ≤ 1.8696°C，Miami ≤ 3.4206°C，四城等城市/等日期 MAE ≤ 3.8032°C。任一失败即不升级；不得增加 C4 或按城市选择不同方案。Seattle/Miami 的 0.20°C 容忍度没有独立经验校准，只是本计划事先冻结的建议门槛。

### 已识别但不改合同的问题

1. 四城已揭盲，压力测试不能构成新的独立确认。
2. C2 的海拔范围只是粗支持判断，在边界处不连续，也不能捕捉全部外推风险；本轮不事后平滑。
3. C3 只有 132 个有效源城市—日期，内层折样本更少；固定小树限制复杂度，但估计仍可能不稳定。
4. d−1 Daymet 字段的观测日期含义已存在于历史特征合同，但产品在目标时点前实际发布的证据未在本轮建立。因此 C3 至多支持历史重建主张，不能自动扩展为实时预测。

## 5. level + anomaly 与尾部误差审计

23,667 个完整预测行全部满足 `absolute = level + anomaly`，最大数值差为机器精度范围。143 个完整城市—日期的 anomaly 中位数最大绝对值为 `2.22e-16°C`，确认中心化在完整固定预测集合完成。

## 6. 实施准备结论

**结论：本地已有数据足以在另行授权的阶段 2 执行固定 C1/C2/C3 比较，不需下载新数据。** 可复用：

1. 原完整 M3 保存模型及其中的原 anomaly 组件；
2. 固定 QA4K 的源城市评分行 OOF，用于原 M3/B1 基准复现；
3. 四城完整集合的冻结 B1/M3 预测与四城评分行；
4. 已认证的四源 253,632 行、四城 23,667 行 46-feature predictor 完成产物；
5. 已有源 QA4K 目标、日期和空间块。

最小缺口不是数据，而是**尚不存在的固定候选计算产物**：阶段 2 仍需在每个源折内拟合/构造 C1/C2/C3，并对 held-out source 的完整预测集合先生成预测、完成完整集合中心化，再映射到评分行；随后按固定规则选出唯一源候选，才可一次性对四城压力测试。该计算需要新的独立执行授权。本轮没有预先计算任何候选值。
