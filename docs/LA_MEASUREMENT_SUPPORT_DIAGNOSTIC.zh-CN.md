# LA 目标观测支持敏感性诊断

## 结论

本轮没有发现应优先处理的“有效像元位置变化”问题。在预先固定的共同空间支持定义下，46 个既有开发日期、41,106 个社区—日期观测的相对目标平均只变化 **0.0134°C**（按日期与空间块等权；日期 bootstrap 95% 区间 **0.0090–0.0183°C**），远低于预设的 **0.20°C** 优先阈值，三个年份也均未达到 0.15°C。

这只说明：在现有 QA4K、固定 eligible-land 分母和本轮相邻过境配对规则下，剩余误差由有效像元组成变化主导的证据较弱。它不证明所有测量误差都不重要，不证明天气是剩余误差的原因，也不构成模型升级。现有模型保持默认。

## 范围与预先固定的规则

结果计算前已在 `experiments/la_measurement_support/experiment.toml` 固定全部规则：

- 仅使用 LA 2022–2024 年既有严格时间向前 OOF 日期；不读取 LA 2025 或外城目标。
- 每年内按日期升序贪心配对不重叠的相邻日期，间隔不超过 16 天，并要求 WRS path/row 集合相同；最终为 23 对、46 个日期。
- 共同支持严格定义为：固定 eligible land ∩ 日期 1 的 QA4K 有效像元 ∩ 日期 2 的 QA4K 有效像元。同一对日期的两个目标使用完全相同的像元位置。
- 每个社区至少保留固定 eligible land 的 60% 且不少于 20 个共同像元；社区必须在日期对的两个日期都进入原评分集。
- 原目标、共同支持目标和预测均在相同保留社区集合内按日期取中位数中心化。
- 可识别性停止门槛为：总体保留率至少 70%，每年至少 60%，至少 40 个日期，并保留至少 80% 的原空间块。
- 判断值得优先处理的门槛为：主敏感性至少 0.20°C，且至少两个年份分别达到 0.15°C。结果产生后未更改配对、覆盖或判断门槛。

本轮没有下载数据、拟合或选择模型、改变 QA、改变 eligible-land 分母或筛掉困难样本来重算原性能。

## 可行性盘点

本地缓存足以直接做像元级核查，而不是用社区汇总相关性代替：

| 问题 | 本地证据 | 判断 |
|---|---|---|
| eligible land 是否固定 | 1,096 个 tract 的固定 zone raster、WorldCover eligible mask、`eligible_pixel_count_static` 与像元身份哈希均保留 | 固定，且本轮逐 tract 核对分母一致 |
| 有效比例是否相近 | 汇总表保留每个 tract-date 的 `valid_pixel_count` 与 `valid_fraction` | 可判断比例，但比例相近不代表位置相同 |
| 有效像元位置是否相同 | 汇总表本身不保存位置；177 个 scene、90 个日期的地理配准 LST、QA_PIXEL、ST_QA、cloud-distance、QA_RADSAT 与 source-coverage 栅格仍在 | 可由缓存重建精确位置并取交集 |
| 过境与质量来源 | scene IDs、platform、WRS 来源、ST_QA、cloud distance、coverage 均保留 | 足以审计本轮支持构造 |

为排除缓存与正式目标表不一致，程序还用每个日期自身的有效像元重建原 tract 中位数，并与认证 QA4K 目标逐值比较；最大绝对差为 **0.0°C**。

|---|---:|
| 原 OOF 日期 | 49 |
| 共同支持配对日期 | 46 |

| 保留行 | 41,106（92.23%） |
| 年度保留率 | 2022: 93.40%；2023: 94.38%；2024: 89.15% |
| 保留空间块 | 69 / 71 |
| 相对目标绝对变化（主指标） | 0.0134°C |
| 日期 bootstrap 95% 区间 | 0.0090–0.0183°C |
| 年度相对目标变化 | 2022: 0.0117；2023: 0.0129；2024: 0.0157°C |
| 未中心化目标绝对变化 | 0.0121°C |
| 原模型在匹配行上的相对 MAE | 1.1100°C |
| 改用共同支持目标后的相对 MAE | 1.1117°C |
| MAE 变化 | +0.0017°C |
| 共同支持占 eligible land 的中位数 / P10 | 1.0000 / 0.9954 |
| 共同支持质心位移中位数 / P90 | 0.00 / 1.49 m |

三个未进入配对的 OOF 日期为 2022-09-03、2023-05-17 和 2023-10-24。样本损失未触发任何停止门槛，但保留率在 2024 年最低，因此结果仍只适用于本轮固定共同支持规则；不能推广为对所有云、边缘或观测几何误差的否定。

这里的 **44,571 行不是完整的 47,142 行原验证集**。两者相差的 2,571 行全部来自未能按预先规则组成非重叠相邻日期对的三个日期：2022-09-03 为 1,085 行、2023-05-17 为 787 行、2023-10-24 为 699 行。它们不是共同支持门槛造成的排除。44,571 行是进入日期配对资格的原评分子集；共同支持的 60%/20 像元门槛随后再保留其中 41,106 行。因此，本诊断只识别 46 个已配对日期上“相邻同 WRS 过境之间有效像元组成变化”的敏感性，不覆盖三个未配对日期，也不覆盖无法进入原 OOF 评分集的低覆盖日期。

## 独立验证方案

现有 LA 日期盘点如下：2020–2024 共 90 个日期，其中按不变 QA 分别有 7、9、19、14、16 个 usable 日期，总计 65 个。2020–2021 已进入训练；2022–2024 的全部 49 个 usable 日期已反复用于开发。未通过日期 QA 的 25 个日期不能为了增加样本而重新定义为可用。因而本地不存在从未参与训练、模型选择或诊断的 QA-eligible 2020–2024 LA 日期；LA 2025 继续冻结，不能再承担新的开发或“第二次盲测”。

下一次有效证据必须来自未来完整日期，并分成两个不重叠阶段：

1. **新开发批次**：在看到目标前写入唯一候选、全部特征处理、缺失处理、固定 QA、完整预测集合中心化、主指标、5% 实际改善门槛和停止规则。连续纳入预先定义季节内的全部合格过境，不因中途结果停止；按现行协议累计至少 30 个 usable 日期，覆盖全部可用空间块。若一个季节不足，就跨季继续，不降低 QA。
2. **独立确认批次**：开发候选冻结后，再收集不重叠的后续至少 30 个 usable 日期。目标打开前先提交全体日期预测；只做一次主评估，不再用确认结果选特征、改 QA 或调模型。若新开发批次用于选方案，它不能同时证明方案成功。

主指标继续使用日期等权、日期内空间块等权的相对 MAE，实际有意义的改善保持 5%；不以 tract-date 行数充当样本量。并行报告逐日期与逐季稳定性、配对日期×空间块区间、最热 20% 社区识别、完整预测集合中心化敏感性和冻结绝对温度输出的 MAE。

如果未来考虑新增动态信息，进入候选前必须同时说明：它补充了当前 23 特征没有的什么信息；空间分辨率是否足以表达城内差异；时间尺度是否匹配过境；历史重建是否完整；以及在目标日前是否已经实际发布。目标场景观测几何和质量信息仍先作为测量诊断，不默认进入目标日前预测模型。

## 最终决策

1. **是否发现值得优先处理的测量支持问题：否。** 在本轮固定、可识别的共同支持检验中，效应比预设阈值小约一个数量级。
2. **下一项最值得补充的信息：新的、前瞻冻结的 LA 完整日期。** 它是建立独立证据的必要条件；采集时应继续保留像元级目标支持、QA 与观测几何，并为任何拟议动态预测量保存可核验的发布时间。若必须选一个模型信息方向，优先寻找目标日前可发布、具有城内空间梯度、且不与现有 d−1 Daymet 信息重复的单一动态场，而不是继续搜索窗口。
3. **仍不能成立的结论：** 不能断言测量误差整体不重要，不能断言剩余误差由天气造成，不能宣称任何新候选已提高精度，不能把 2022–2024 或 LA 2025 再称为独立确认，也不能宣称模型达到精度上限。

机器可读结果位于 `exports/LA_MEASUREMENT_SUPPORT_DIAGNOSTIC/summary.json`；匹配行和日期/空间块聚合表位于同一目录。
